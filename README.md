# 🚀 Freistellung Express

Jednoduchá webová aplikace pro vyřízení **Freistellungsbescheinigung (§48b EStG)** pro osoby pracující v Německu.

👉 Rychlé, přehledné a bez zbytečného papírování.

---

## 🌐 Live demo

👉 https://mikyvondra.github.io/freistellung-express/

---

## 💡 O projektu

Tento web pomáhá OSVČ a firmám získat **Freistellung**, aby:

* nepřišli o **15 % z faktur**
* nemuseli řešit německé úřady
* zvládli vše online během pár minut

---

## ⚙️ Funkce

* 📄 Online formulář pro zadání údajů
* ✅ Validace vstupů
* 💳 Napojení na Stripe platby
* 🏦 Možnost bankovního převodu
* 📩 Odeslání dat přes Formspree
* 📱 Responzivní design (mobil / desktop)

---

## 🛠️ Technologie

* HTML5
* CSS3 (custom styling)
* Vanilla JavaScript
* Formspree (backend formuláře)
* Stripe (platby)
* GitHub Pages (hosting)
